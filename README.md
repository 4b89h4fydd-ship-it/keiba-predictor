# 競馬展開AI PWA Cloud v1

パソコンなし運用を想定した、iPhone Safari向けPWA＋クラウドAPIのセットです。

## できること
- 日付 → 中央/地方 → 会場 → 1R〜12R
- 馬齢・性別・斤量
- 騎手・調教師の過去成績
- レース時点までの獲得賞金
- 距離・競馬場・馬場・季節・天候
- 直近レースのタイム・着順・通過順位
- 1 先行馬占有率
- 2 脚質マップ＋脚質点（昇順）
- 3 5局面隊列
- 4 A/B/C
- 5 ◎○▲☆△注

## 現在のデータ接続
- 地方: NAR取り込み用バックエンドを同梱
- 中央: JRA-VAN JV-LinkがWindows専用のため、Windowsブリッジまたは別の合法な中央データ供給源が必要
- API未接続時: サンプルデータで画面確認可能

## 公開後のiPhone操作
Safariで公開URLを開く → 共有 → ホーム画面に追加

## Cloud deployment
Dockerfile と render.yaml を同梱。GitHub等のリポジトリへ置いてHTTPSのクラウドへ公開する前提です。
