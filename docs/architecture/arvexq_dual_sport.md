# ARVEXQ — 競馬・競艇の共通アプリ構造

## 対応ページ

- `/` および `/keiba/` は既存の競馬アプリを維持。中央・地方の既存予想は変えない。
- `/kyotei/` は競艇専用のHTML/JS/CSS。競馬のapp.js、予想計算、データ取得は読み込まない。
- 両方の上部に「競馬｜競艇」タブを配置し、各々独立URLへ移動する。
- 後日、競艇側の予想・データ・検証が完成した段階で、親トップ画面およびPWAアプリアイコンを再設計する。

## 競艇の予想に求める条件

- 3連単のみ。1レースの買い目は最大6点。6点の強制選定なし・見送り可能。
- ARVEXQ競馬の役割印の意味を共通化：◎【単】は1着候補、◎【軸】は3着以内の安定軸。
- 両方を満たせば両印を表示。A/B/Cの根拠を個別に検証し、Aでは「A」の添字を省略。
- 印は予想エンジンの1着・3着内推定に基づく。買い目との矛盾を禁止。
- 特徴量：全キャリアと直近実績、ST、モーター、進入、展示、節間成績、風向、波高、水面、1マーク攻防。
- 全120通りの順位確率を時系列バックテストで校正。実際のオッズがあるときは期待値を検討。
- 朝の予想は記録し、展示後は実データ変更で再計算。発走前の版は不変保存。
- 公式データ等の取得許諾・利用条件を確認したうえで単一の競艇取得パイプラインを実装する。
- 学習・検証では、当時利用可能だったデータ以外を使わない。
- 的中率・回収率と◎【単】1着率、◎【軸】3着内率を測る。

## 現段階

本コミットで実装しているのは独立ページと切替ナビゲーション、全国24場を選べる画面だけ。
**実レースデータ、予想モデル、結果・払戻検証、トップ/アイコンの刷新は未実装。**
接続確認ができるまで競艇レース名、印、買い目、オッズを捏造表示しない。

競馬側の既存バグを増やさないよう、将来の競艇DB・予想ロジック・API・ジョブは競馬と分離する。
