# Phase 31 — Observed archive file presence

For days between selected saved archive pairs, the read-only calendar audit records whether neither source file exists, just a racecard exists, just a saved manifest exists, or both exist. The distinction is filesystem evidence only, not proof of a race, cancellation, official coverage, or complete stored payload. When invoked without a directory, presence is explicitly `not-checked`. The existing paired-day selection, SHA-256 verification, collectors and production paths are unchanged. JRA/NAR are not inferred from absent daily files.
