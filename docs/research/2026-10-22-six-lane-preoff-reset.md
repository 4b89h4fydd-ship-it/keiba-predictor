# ARVEXQ 予想6系統・選択的リセット／Stage 1（隔離研究）

2026-10-22。**本番への統合・デプロイを前提としない。** 既存の200箱、D1、公式出馬表、過去走、結果、保存済み予想は削除しない。旧 `arvexq/forecast/engine.py::build_prediction` は引き続き無効（`None`）であり、起動しない。

## 入力と監査可能性

`arvexq.rebuild.inspect_preoff(snapshot, receipt)` は**既存の発走前特徴量凍結**と、それとは別の取得ログから発生した `receipt` の組だけを受け付ける。発走前の収集入口は既存 `arvexq/forecast/preoff_capture.py::capture_preoff_features`、検証入口は `arvexq/forecast/frozen_research_input.py` を再利用する。新たなスクレイパーや発走後からの過去データ再構築はしない。

チェックする契約：特徴量と別保存レシートのSHA256一致、正式な発走前取得時間、発走時刻、レース日、全頭・馬番・馬名と公式出走馬番の完全一致、勝者や結果などの情報混入排除、中央(`jra-`)と地方(`nar-`)の回路分離、帯広/ばんえいと障害の専用モデル未提供時の拒否。

**注意**：自己記載の取得時刻＋自分で計算したレシートハッシュだけでは外部の収集時刻を証明できない。発走前に第三者確認可能な append-only ログ等へ保存済みであることの外部監査は引き続き必須。今回の `independentStorageTimestampVerified` は常に `false`。

## 六つの系統

| 系統 | Stage 1 |
| --- | --- |
| 1. 能力 | 過去走の上がり、着順品質、速度等、取得済みの特徴量の有無を各馬ごとに数える。**能力順位は算出しない** |
| 2. 脚質 | 先行・位置・終盤速度の過去走情報のカバレッジを調べる。**脚質を推測して決め付けない** |
| 3. 展開 | 脚質・流れに使える元データの件数のみ出す。**展開確率・展開シナリオは未出力** |
| 4. 確率 | 中央/地方別の時系列holdout、全頭の勝者ラベル、校正と独立未来検証を終えるまで `None` |
| 5. 印 | 認定された確率がないため空配列。旧保存印を新規予想と混ぜない |
| 6. 買い目 | 3連系の同時確率、発走前の本物のオッズ、期待値・時刻の独立検証がないため空配列 |

地方では公開地方平地、中央では中央平地のみ対象。モデルを共有したり、地方の結果から中央馬を自動補完したりしない。両系統の未来holdoutは別々に作る。事後結果を含むrace detail、偽のゼロ埋めや未実績の外部AI重み付けは禁止。

## 使用例（読み取り専用）

```bash
PYTHONPATH=. python scripts/arvexq_six_lane_readiness.py ./verified_preoff_capture_receipts.jsonl
```

JSONLの1行は `{"snapshot": <発走前凍結特徴量>, "receipt": <別保存の取得記録>}`。中央・地方別の利用可能レース数、取得日数、能力/脚質の観測件数、拒否理由を標準出力に表示する。条件不適合・入力空の場合終了コードは2。外部時刻監査や的中率、勝率・ROI、確率校正の承認はこのツールでは行わない。

## 次の合格条件

1. 発走前に保存済みで外部時刻証拠のある全頭のレースを**実件数で**確認する。ない場合は実績を0として「不足」を表示する。
2. #401の全頭結果照合・原本hash拒否の研究を独立CIで検証し、中央/地方の訓練・校正・未来holdoutを日付単位で分離。学習用レースが十分あることを示すまではモデル学習の成績を作らない。
3. 能力・脚質・展開の独立検証済みモデルだけを段階接続する。後段の `win / top2 / top3 / exacta / trifecta` は校正評価と全組合せ整合性の検査を完了してから。
4. 人気艇/馬に依存せず、投票締切前の本物の賭け率・オッズでEVを計算。発走後のオッズを使った回収率の捏造を禁止。
5. 十分な独立未来データで baseline より改善しなければ、印・推奨買い目を**出さない**。研究段階のコードを public UI / API / D1 write path へ自動導入しない。

このStage 1は**「検証できる入口と欠損の可視化」**であって、予想の完成や利益の証明ではない。
