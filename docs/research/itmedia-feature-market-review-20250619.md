# ITmedia 2025-06-19 記事を踏まえたARVEXQ研究項目

参照: https://www.itmedia.co.jp/news/article/2506/16/1250616118/ （全4ページ、2025-06-19公開）
元記事はヤナシ社長へのインタビューであり、再現可能なモデル学習コードや優位性を保証する実験結果ではない。売買収益の保証にも使わない。

## 先行研究との接続

- 既存研究 `arvexq/research/ranking_challenger.py` は race-group LightGBM LambdaRank の Ability（同一レース内の着順上位）と ANA（発走前人気を上回る上位入線馬）を中央・地方別に研究するもの。
- 記事から採るべき追加仮説は、アルゴリズム名の変更ではなく **新しい発走前特徴量の品質** と **能力評価・市場評価の乖離** にある。
- 本番v9bは温度補正と市場オッズ混合を行う。研究モデルの未校正ランキングスコアをそのまま勝率・期待回収率・プロオッズと呼ばない。

## 特徴量候補と適用可否

| 候補 | 必要な入力 | 実装上の扱い |
| --- | --- | --- |
| 馬具変更（ブリンカー等） | 当該レース発走前に確認できる現・前走装備 | 取得元と日時、欠損率を保存。ソース権限確認後にアブレーション |
| 前日までに判明する追い切り・育成情報 | 権利上利用可能な原データと更新日時 | 未取得・使用許諾未確認なら未適用。補完値で埋めない |
| 初角・3角・4角の位置取りと相手関係 | 過去走における事前保存済み通過順位・相手レベル | ability特徴へ追加する候補。**当日の結果・通過順位は入力禁止** |
| 当日馬体・馬具・パドック | 予想発行前の観測時刻付きスナップショット | 前日予想とは分け、T-30等の遅い予想レーンのみで検証 |
| 予想家の傾向・合成プロオッズ | 各予想家の発走前予想ログと**商用利用許諾** | 無許諾スクレイピング・再配布禁止。無い場合は実装しない |
| 自前の適正オッズ | 実レースで校正済みの独立勝率モデル | `fairOdds=1/calibratedP`。ランキング生スコアを変換しない |

## 検証の設計

1. フリーズ済み発走前情報だけを使い、入力のソース・取得時刻・featureHashを保存。結果はラベル・払戻採点のみに用いる。
2. 中央平地／地方／新馬／障害を混同せず、十分なレース数がない区分は未判定。帯広ばんえいは対象外。
3. 同一期間・同一レースを対象に、本番v9b、Abilityのみ、Ability+ANA、さらに合法的に収集できた新特徴量を順に比較。1要素ずつ除外するアブレーションを採用。
4. 順位指標：◎1着率、◎3着内率、勝ち馬Top3/5捕捉率、NDCG@3。確率が校正されたレーンだけLogLoss・Brierを比較。
5. 購入判断：発行時点オッズ・実際の払戻を用い、単勝/複勝/既存R24の購入額、回収率、最大払戻除外後回収率、購入レース率を並列比較。未校正スコアからEVを算出しない。
6. 期間はレース日で時系列分割し、train/valid/testを混ぜない。採用閾値はvalidまでに固定。日付単位のブートストラップ信頼区間と直近シフトも確認。
7. 著者や予想家の自称ROIをARVEXQの実測ROIに転記せず、未改善なら本番v9b+R24を維持。
