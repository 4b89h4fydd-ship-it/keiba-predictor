10月16日の対象は名古屋・園田・川崎の各12レース。中央は当日の取得対象に開催レースなし。地方36レースはNAR公式ページを直接取得し、全レースの上位3頭が保存結果と一致。公式HTMLのSHA-256をJSONに保存。
