# ARVEXQ刷新候補の実装・検証記録

全面刷新・main統合・本番反映は未完了。技術テストと精度採用条件を区別する。

## 実装した範囲

- 新候補の固定加重点を削除し、日付を限定した学習型の全過去走分析へ置換。生涯成績の網羅が未確認なら「確認できた履歴の範囲」と明記する。
- 過去の着順、近況、コース・距離・馬場別実績、位置変化、間隔、距離変更、斤量、騎手一致、比較可能な着差・上がり順位など、観測できた特徴から係数を学習。欠損は欠損指標と学習データ平均の標準化で表現し、架空の実測値は出力しない。
- 中央・地方、平地・障害・ばんえいは同一モデルを流用しない。全学習日より後の対象だけ予測し、学習対象レースとの重複を拒否する。
- 通常・前へ進出・後方に控える位置取り感度を比較。これは展開の発生頻度を学習した完成版ではない。シナリオに根拠のない混合確率を付けない。
- 全頭の文章、◎の勝ち切りと安定性の整合、各印の選定理由を生成。勝ち切り最有力馬の安定性が比較上位に届かない場合は◎を強制しない。単勝用と軸用で別馬を本命にしない。
- 予想本文は日本語の文章。数字・英字を含む馬名は本文用に正規化し、元の馬名・馬番は構造化データに保持する。
- 全八券種を同一の条件付き着順分布で比較。ワイドなど重複的中は和事象として集計する。券種内の点数上限は十点。未検証の候補から実運用のおすすめを確定しない。
- 発売券種・複勝の対象着順・枠番・発走前オッズを推測しない。不足は見送り理由とする。
- 公式払戻の複勝・枠連も集計できるように既存の払戻パーサーを修正。
- 事後分析は元の発走前印・買い目とは別の返却データ。既存の取得・保存経路と原本は変更していない。

## データと再現

引き継ぎ資料 `ARVEXQ_execution_evidence_20261016.zip` の `evidence/20261012` と `evidence/20261016` を使用。
これらは過去の研究で評価済みの日付であり、未使用データの検証ではない。取得応答は事後保存なので、全フィールドが当時発走前に既知だったことまで証明しない。

固定学習設定は結果を見る前に実装した設定のまま。今回の評価対象で再調整していない。学習済み係数・入力証拠のハッシュ・対象レースの取得ファイルハッシュをJSONに保持する。現レースの結果・最終人気・オッズ・現馬体重は学習特徴に入れない。

```bash
PYTHONPATH=. python scripts/arvexq_learned_scenario_evaluation.py \
  --input-dir /path/to/extracted/evidence \
  --train-date 2026-10-12 --evaluate-date 2026-10-16 \
  --output /path/to/diagnostic.json
```

学習に使えたのは中央十八レース、地方平地三十五レース。新馬など履歴のない馬だけのレースは学習できず、ばんえいは平地モデルの学習対象外。学習と評価のレースIDの重複はゼロ。

| 地方・事後診断 | 実測 |
|---|---:|
| 対象レース | 三十六 |
| 全頭履歴がなく分析不能 | 十一 |
| ◎を採点できたレース | 二十五 |
| ◎一着 | 十二／二十五（四十八パーセント） |
| ◎三着内 | 十八／二十五（七十二パーセント） |
| おすすめ買い目 | 全件見送り |
| おすすめ的中率・回収率 | 計算不能（推奨なし） |
| 見送り率 | 百パーセント |
| 模擬購入金額 | ゼロ |

中央は評価対象日に取得済みの対象がなく、今回の汎化精度は未確認。今回の入力では全頭履歴を分析できた三百六十頭についても、生涯履歴の完全取得を証明できた馬はゼロ。全過去走を取得した完成版とは報告しない。

二十五件中、一着を外した十三件の内訳は、二着四件・三着二件・着外七件。これは選定結果の分類であり、競馬上の因果的な敗因ではない。残る十一件は全頭履歴不足により候補を出していない。おすすめ的中率八十パーセントは未達成・未検証。全見送りを成功扱いしない。
