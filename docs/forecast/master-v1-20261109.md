# ARVEXQ master v1 / 全頭徹底分析型（候補レーン）

2026-11-09。ユーザー提示の18章マスタープロンプトを再現可能な数値計算・出典状態・券種判定に分離した候補です。既存の本番v9b / R24と凍結済み発走前予想は上書きしません。

## 入力と境界

- normalize_race の発走前出馬表・過去走だけを使用。当日以降の日付の過去走は除外。帯広ばんえいを除外。取消馬は分布に入れません。
- 中央平地 / 地方 / 障害 / 新馬を分離。新馬は血統・調教の検証データがない間、架空の能力順位・確率・印を出しません。
- 入力オッズの公式性は外部取得段で検証が必要です。出所未検証のオッズは券種別EVとして使いません。
- 映像追跡、馬体、調教、血統、同日トラックバイアス、風向き、初角距離の結合が未検証の場合は非適用。

## 100点スコア（順位用の暫定配点）

| 区分 | 上限 | 現時点で使う事実 |
|---|---:|---|
| 基礎能力 | 24 | 実測着差・相手クラス・クラス替わり |
| 近走 | 15 | 着順順位・安定性・3着内実績 |
| コース距離 | 14 | 同場・距離・芝ダート一致の実績 |
| 展開 | 15 | 過去走初角位置・4角からの伸び、3シナリオ |
| 馬場 | 8 | 既知の馬場状態での実績 |
| 調教状態 | 8 | 計測根拠未接続につき非採点 |
| 騎手厩舎 | 6 | 同騎手の当該馬過去走のみ |
| 枠順 | 4 | コース別実証未接続につき非採点 |
| 斤量ローテ | 6 | 過去走からの斤量差。休養差は未採点 |

スコアは観測項目の配点だけで割り、未知の項目をゼロとして扱いません。証拠被覆率を表示し、人気やオッズは能力スコアに混入させません。配点は過去検証で有効性を確認していない暫定値です。

## 確率・反証・買い目

- 各馬の証拠充足率が40%未満なら全馬の確率を非公開。
- それ以外は暫定指数係数とPlackett-Luce着順同時分布から勝率・2着内率・3着内率を算出（総和1/2/3）。
- ペースはslow/normal/fastの3種類。ただし出現確率は未検証のため数値や1/3平均を創作しません。各条件での3着内率レンジのみ示します。
- ◎○▲△☆は通常シナリオの勝率順で機械的決定し、3着内率最上位は別に表示します。
- 複勝・ワイド・馬連などの組み合わせ確率は、個別確率の積ではなく着順同時分布で計算。
- 的中率優先/バランス/穴馬の候補を分離。穴馬は市場順位との対比条件を満たす場合だけ選定。
- 確率未校正かつ券種別公式オッズ未確認のため、候補を示しても購入判定は見送り、1000円配分は0円。架空のEVを出しません。
- 反証はペース変化・馬場バイアス・未確認の馬体/調教等の3類型で点検します。

## 本番採用ゲート

同一日同一レースのv9bと完全ペアで発走前固定した候補を検証。中央・地方・新馬・障害を別々に評価し、◎勝率・◎3着内率・log loss・Brier・的中率・回収率・最大払戻除外・日付単位の信頼区間・発売時点オッズを照合すること。未検証の暫定配点で本番予想を置換しません。
