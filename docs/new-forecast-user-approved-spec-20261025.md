# ARVEXQ 新方式 — 2026-10-25 ユーザー再確認

この文書はユーザーが既存チャットの仕様を改めて承認した決定記録。実装完了・本番反映・性能実証を示すものではない。

## 最上位目的
- 各レースで実際に勝つ馬を選ぶ精度を優先する。
- 学習完了を待たず、既存経路への実装と未来レース検証を並行する。
- 中央競馬（JRA）と地方競馬（NAR）は予想方式・評価を完全分離する。
- 新馬と障害は専用分析として扱う。帯広ばんえいは既存の除外指示を維持する。

## 新方式の処理構成（旧方式・旧6系統を置換）
1. 既存取得経路から事実データを収集し、過去レース映像から全馬追跡（位置・速度・進路・出遅れ・距離ロス・不利・加減速）を内部分析する。取得不可は捏造しない。映像画面を新設しない。
2. **能力分析**：近走、着差、相手関係、適性、状態、血統など。
3. **展開分析**：みねた氏の公開手法を主体に、先行候補、隊列、ペース、位置取り、コース、騎手を評価する。
4. **確率計算**：能力・展開・複数予想家の手法・独立AIの評価を融合し、勝率、3着内率を算出する。架空の実在予想家の印は作らない。
5. **印の決定**：融合の計算結果を◎○▲△☆へ反映する。AIの主観による印の上書きを禁止する。
6. **おすすめ買い目・厳選／特別選定**：実測オッズと的中確率・期待回収率から判断し、条件不足は見送りとする。

## 既存構成との区別
- この六つは**新方式の処理段階**であり、旧六系統を残すという意味ではない。
- PR #469 の「みねた型・近走型・適性型・ロジスティック・ベイズ」の五つは研究実装の内訳であり、ユーザーの承認した新方式そのものと同一視しない。
- 旧方式、既存旧六系統を新規予想の計算・表示経路へ混入させない。
- 既存レースデータ、凍結済み発走前原本、200項目独立化の研究成果は消去しない。
