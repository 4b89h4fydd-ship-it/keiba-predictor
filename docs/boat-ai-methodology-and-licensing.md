# ARVEXQ 競艇 AI — 予想研究・商用公開要件（2026-10-12）

## 目的
3連単のみ・最大6点。6艇の印（◎【単】/◎【軸】とA/B/C）・1着確率と3着内軸確率・買い目・オッズ・成績を同一発走前スナップショットで整合させる。中央/地方の競馬予想器とは独立した構成にする。

## 予想家・公開AIから検証する研究群
公開予想をそのままコピーするのではなく、予想家の着眼点を数値化し、時系列で再現できるか評価する。

1. **進入・1マーク型**: 進入変化、深イン、ダッシュ勢、イン逃げ率、各コースの逃げ／差し／まくり／まくり差し可能性、スタート隊形。スタート展示は本番進入を確約しない。
2. **選手能力型**: 全国/当地勝率（0～10点）、2/3連率（0～100%）、コース別1着・3連率、直近の節間結果、同場、同条件、級別、F/Lと出場状況、直近の調子。
3. **モーター・展示型**: モーター2/3連率（0～100%）、直近整備・部品交換、展示タイム・回り足・直線、チルト、体重、スタート展示進入/ST。
4. **水面・天候型**: 会場別風向・風速・波高・水温・気温・潮位（該当会場）、時間帯とコース有利不利。過去の同水面状態があれば条件別統計にする。
5. **機械学習/確率型**: コース別事前確率、Plackett-Luce型の順序確率、GBDT/ランダムフォレスト、階層ベイズ、複数専門家のアンサンブル。厩舎等の競馬因子を競艇に持ち込まない。
6. **市場・価値型**: 3連単120組オッズ、変更時刻、観測確率と市場価格の差、購入点数・資金分配。単純に高オッズだから買わない。精度/校正された確率が必要。

## 最重要: 実データと取得権限
- 公式: https://www.boatrace.jp/owpc/pc/extra/data/download.html （レーサー期別・競走成績・番組表）
- 公式直前情報: https://www.boatrace.jp/owpc/pc/race/beforeinfo （スタート展示・選手/モーター・水面・波）
- 公式3連単オッズ: https://www.boatrace.jp/owpc/pc/race/odds3t
- 公式選手直近成績: https://www.boatrace.jp/owpc/pc/data/racersearch/back3
- 権利条件: https://www.boatrace.jp/owpc/pc/extra/policy.html
- 無断の全文転載、無断大量取得、商用無許諾の配信をしない。公表資料の閲覧可能性は商用二次配布の許可ではない。
- 競艇の **単一正規化日次ファイル** は `/sports/boat-data/YYYY-MM-DD.json`。全画面・オッズ・結果・全艇診断はその同じファイルを参照。修正時に別のWeb取得経路を継ぎ足さない。
- `scripts/arvexq_boat_publish.py` は商用利用権限を明示した検証済み入力のみを公開する。現時点では実運用の権限付きフィードが未接続で、出走表や結果の完全表示は未達。

## 予想確率と表示仕様
- 常に3連単120通りを評価し、確率を合計1に正規化する。
- 1着確率 `P(1着)` と3着内確率 `P(1~3着)` は独立して積算する。1着に最強の艇と軸向きの艇が異なってもよい。
- ◎【単】と◎【軸】が同艇で信頼Aなら両方併記。信頼度は過去の校正済み的中区間に基づき、未校正データでAを付与しない。
- 競艇の注は「下位順位」というだけで乱発しない。警戒すべき勝率/進入/展示/穴の根拠が確認できた場合だけ。
- `1-23-234` → `1-2-3, 1-2-4, 1-3-2, 1-3-4` の **4点**。同一艇が複数着順に出る組み合わせを除去。
- 各点を「3連単 / 直近公式オッズ / 更新時刻 / 購入額 / 想定払戻」で行表示。個別オッズがなければ「—」。架空の倍率を作らない。
- 配信前予想の印・買い目・基準オッズ・確率は発走前の不変スナップショットに保存。展示後に修正する場合は旧版を残して変更理由と時刻を記録する。結果確定後は事前印を後から作り直さない。

## 厳選・特別の審査
- **毎日1件以上の公表を目標** とするが、不十分な情報/校正では虚偽の厳選を作らない。
- 厳選: 発走前に条件が揃い、その中に3連単15倍以上の **的中可能性を検証した買い目** を含める。15倍以上だけでは条件を満たさず、校正確率と期待値もチェックする。
- 特別: 注目開催・注目レース等について、厳選とは別に予想公表を確定する。結果的に高配当が出たレースを後から選ばない。
- 掲載候補を朝に全会場スキャンして決定し、後から黙って入れ替えない。データ更新や出走取消による訂正のみ追記訂正。
- オッズ大変動後には買い目金額/期待値を更新しても、発走前買い目の原本とその時点の根拠を残す。

## 検証と精度ゲート
1. 開催日順にwalk-forwardでモデルの訓練/検証を切る。開催場/選手/節間のリークを防ぎ、展示・当日オッズ・結果の事後情報を事前学習サンプルに混入しない。
2. 1着勝率、3着内軸的中率、3連単最大6点的中率、3連単純利益/回収率を別々に計測。
3. 120組のlog loss、Brier、信頼度A/B/Cの校正、月/場/選手/風条件別の成績、サンプル数を公開・検証。
4. 公式事前オッズの市場ベースライン/単純1コース支持率/選手勝率のみ/モーターのみを比較し、各要素を除外するアブレーションを行う。
5. 本番配信ゲート: 権利許諾、出走6艇、締切時刻、公式オッズ、実績データ、時系列検証合格、発走前保存が全部揃うこと。バックテストがない段階で精度や回収率を宣伝しない。

現行 `prediction-model.js` は **未学習の試験的な数理ベースライン** であり、検証済み高精度AIを名乗れる段階ではない。
