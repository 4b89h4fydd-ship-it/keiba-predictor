公開ページを取得し、URL・取得時刻・HTTP状態・元バイトSHA256を保存。原HTMLは
`/workspace/arvexq-evidence/run3/sources/`に保管し、リポジトリへは正規化した事実データの
テスト用キャプチャだけを追加。キャッシュは再読込時に元バイトハッシュを照合する。
NAR公式の動的出馬表はrobots.txtで巡回禁止だったため新コレクターで使用しない。
楽天のrobots.txtは対象パスを禁止せず60秒の間隔を指定。コレクターは間隔と禁止を尊重。
Yahooのrobots.txtは404。公開閲覧と商用再配信・継続取得の許諾は別であり、商用利用の
明示許諾確認を完了したとは扱わない。Firecrawlはクレジット不足のため直接取得を使用。

オフライン再現（Python 3.12、beautifulsoup4==4.12.3）：

```sh
mkdir -p /tmp/arvexq-slice-replay
cp tests/fixtures/clean_slice/*.input.json /tmp/arvexq-slice-replay/
python -m rewrite.slice.run --directory /tmp/arvexq-slice-replay --database /tmp/arvexq-slice-replay/research.sqlite3
python -m rewrite.slice.server --database /tmp/arvexq-slice-replay/research.sqlite3 --port 8765
```

新規取得は`python -m rewrite.slice.collect --directory <新しい保存先>`。
対象は上記2件に限定した検証用アダプター。全日程・全レースの汎用取得は未対応。
過去ページの仕様・提供範囲が変われば明示的に失敗する。同一保存先の異なる入力での
上書きを拒否する。発走前原本の保存基盤とは別テーブルに実際の生成日時で保存し、
過去時刻に偽装しない。

## 能力・展開・買い目の状態

能力は過去走の着順百分位・符号付き着差（秒/km）・経過日数・距離差・同場/馬場種別の
関連度から計算する説明可能なヒューリスティック。パラメーターはAPIへ保存。
学習済みモデルではない。中央と地方は経過日数・距離関連度のパラメーターを分けたが、
種類別の学習・評価を達成したとは扱わない。新馬・障害・現出走表の取消を含む未対応
ケースは分析を拒否し、通常モデルで埋めない。

過去レースで今回の出走馬同士が対戦していれば、同一レースキーで対応付け、着順と
時計を証拠へ保存。地方の相手名は公開表示（省略名を含む）のまま保存。完全な相手
レーティングや未取得馬の能力を推定値で埋めない。

通常・ハイペース・スローペースの3シナリオで、スタート・3角・4角・直線の位置指数を
個別に計算し、全馬の想定順位を返す。スタートは最初のコーナー、直線は最終コーナー
から着順への変化を代理特徴として使用。実測の出脚・直線内の位置や速度ではない。
3角・4角は過去通過順位の別地点を使用。先行候補、展開成立条件、使用件数と代理特徴の
制約を画面/APIへ表示。シナリオ発生確率は未校正なのでnull。

印は能力とシナリオの順位指数から単一経路で決定し、画面はAPIの印を描画する。
ブラウザで予想を再計算しない。オッズは全28頭に公開実値があるが事後取得の最終表示で、
検証済み確率がないため**全券種見送り**。確率・期待値・推奨購入額を生成していない。
この条件分岐が、今回の買い目表示の検証結果である。

## MotherDuckの5件（読み取り専用）

対象は`nar-2026-10-22-園田-01`〜`05`。元バイトを小分けSELECTで読み取り、ローカルで
結合したSHA256がSQL照合時の現在値と全件一致。埋め込み`arvexqFullPayload`を展開し、
バイト長とそのSHA256が**5/5一致**した。外側の馬データは`recentRaces`、
`precomputedMetrics`等を省いた表示用投影で、埋め込み原本とは同じJSONではなかった。

整形条件でも再現しない。したがって「単なる空白差」「原本破損」「修復済み」の
いずれとも断定できない。保存列の計算対象・取込時の変換順序の追跡が残る。
